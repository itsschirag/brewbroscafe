# Brew-Bros Cafe

Static website for Brew-Bros Cafe, Hinjewadi, Pune. No build step.

## Local preview

```bash
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Deploy

Drop this folder on [Netlify](https://app.netlify.com/drop), [Cloudflare Pages](https://pages.cloudflare.com/), or [GitHub Pages]. Publish the project root.

Phone, Instagram, Swiggy, and Zomato links in `index.html` can be swapped for the cafe’s live URLs.
